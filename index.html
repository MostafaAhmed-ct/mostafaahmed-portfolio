Physical Network and VLANs

Built by me, with teammates helping on some of the cabling

Problem

New labs and departments needed a clean, maintainable wired network that could grow.

What I did

  • Installed racks and Cat6 cabling with patch panels and labeling
  • Configured switches and VLANs per department
  • Prepared a price comparison from several suppliers for wiring five computer labs

Result

A documented, segmented network that is easier to maintain and extend.

pfSense Firewall, VPN and Web Filtering

Built by me

Problem

The firewall ran on an old tower PC that hung and slowed the internet.

What I did

  • Migrated pfSense to a Dell PowerEdge R250
  • Set up DHCP and traffic rules between networks
  • Configured pfBlockerNG for domain blocking
  • Set up OpenVPN for authorized remote access

Result

A stable edge with controlled access and secure remote entry for the network, software and security teams.

Centralized Wi-Fi and Guest Network

Built by me

Problem

Every access point was managed on its own, and guests could reach the internal network.

What I did

  • Installed Omada Controller on Windows Server for TP-Link APs
  • Configured a Cisco AP as a Mobility Express controller
  • Built a MikroTik voucher system with time and speed limits and a login portal
  • Isolated guests from the main network

Result

One place to manage Wi-Fi, and a guest network that is controlled and separated.

Windows Server and Active Directory

Built by me

Problem

No central control over users, lab devices or permissions.

What I did

  • Deployed an HPE ProLiant DL380 Gen9 as the main server
  • Created the AD domain, DNS and the OU structure
  • Applied Group Policy to lock down lab devices: no CMD, PowerShell, Control Panel, Registry or USB storage
  • Set up a QNAP NAS for shared folders and backups

Result

Centralized authentication, protected lab machines and a stable, easy-to-manage environment.

Windows ServerAD DSDNSGroup PolicyQNAP

Proxmox Virtualization and Web Server Migration

Built by me

Problem

The website shared a Windows Server with user data, and each new service meant buying new hardware.

What I did

  • Set up Proxmox VE as the hypervisor
  • Moved the website from IIS to an isolated Ubuntu VM running Nginx

Result

Better isolation, a smaller attack surface and no extra hardware cost.

ProxmoxUbuntu ServerNginxLinux CLI

Security Monitoring with Wazuh and Suricata

Built entirely by me

Problem

No visibility into endpoint activity or network traffic.

What I did

  • Deployed a dedicated Ubuntu CLI VM running Wazuh and Suricata
  • Installed Sysmon and the Wazuh agent on all Windows machines

Result

Central log collection and alerts for endpoints and network traffic.
